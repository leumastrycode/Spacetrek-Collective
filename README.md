## ✨ Features

### 👤 Client Features

- **Smooth Login** — A quick pop-up window for signing in and registering, so users don't get redirected back and forth.
- **Project Briefing** — Clients can easily customize their orders by picking the website's purpose, industry, visual style, and color vibe.
- **Draft & Tracking** — Users can save their order drafts and track whether their website is still in progress or already done.

### 🔐 Admin Features

- **Secure Access** — The admin workspace is strictly locked and only accessible to verified administrator accounts.
- **Analytics Dashboard** — Interactive charts showing order trends, popular design choices, and total active users.

## 🛠️ Tech Stack

### ⚡ Next.js
We use Next.js because it is incredibly fast and makes moving between pages feel really smooth. It also makes it easy for us to manage page routes and build APIs in one single place.

### 🎨 Tailwind CSS
It is super efficient for designing the layout. We can set styles directly in our code. This saves us a lot of time and makes the platform look modern and responsive on any screen size.

### 🗄️ Supabase
We chose Supabase to handle our data and user accounts. It gives us a strong database and a solid, secure login system right out of the box, so we don't have to build a complex verification system from scratch.
